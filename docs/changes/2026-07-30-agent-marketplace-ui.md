# 智能体广场 UI 改版

日期：2026-07-30

## 改动

- 将 Memfit 模式下的“技能库”重命名为“智能体广场”。
- 将“新建技能”及新建页签文案改为“创建智能体”，编辑页签同步改为“编辑智能体”。
- 新增智能体广场 Hero、专业场景分类、搜索区和响应式双列智能体卡片。
- 卡片展示真实 Forge 名称、内置推荐状态、更新时间、描述、类型、作者及关联能力数量。
- 保留原有创建、编辑、删除、导入、导出、批量选择、搜索和滚动加载逻辑。
- 使用已有数字员工透明高清人物素材，不引入截图背景或虚构收藏数据。
- 新样式与文案仅在 Memfit / AI SenPike 模式生效，其他产品模式继续使用原技能库页面。
