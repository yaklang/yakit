新建请求序列化、历史会话恢复、定时任务关联会话打开，以及新会话 / 应用初始化的模式重置，均补齐新字段。gRPC int64 字符串规范化，保留 `-1`，非法值回到 0 的服务端默认语义。应用初始化仍沿用既有模式重置策略；历史会话保留并恢复自己的配置。
