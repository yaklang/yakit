# 数字员工切换标签重置

日期：2026-07-30

## 背景

默认员工技能已经接入原版 Milkdown Forge mention，但在欢迎页直接切换员工时，输入组件可能保持同一实例。此时新员工默认标签会被补入，而上一员工的锁定标签仍可能留在编辑器中。

## 改动

- 欢迎页和对话详情页的 `AIChatTextarea` 使用现有 `selectionVersion` 作为 React key。
- 员工切换后重建输入编辑器，从新的 `defaultMentions` 初始化，只保留新员工默认标签。
- 同一员工会话内的清空、首次发送和连续发送仍由原有 `defaultMentions` 恢复逻辑处理。
- 保留用户通过 `@` 添加多标签、mention 提取、请求资源转换、IPC 和模型发送逻辑。
- 修正 resolver 测试中一组乱码中文样例，并新增员工切换版本递增测试。

## 运行检查

- `http://127.0.0.1:2800` 返回 200，Electron 正常进入 AI Agent。
- 页面显示当前员工“首席信息安全官”及技能就绪状态。
- 输入框同时显示默认标签“首席信息安全官”和额外 Forge 标签“警告降噪分析”，多标签共存正常。
- 选择页和工作区响应式样式已复核，未引入固定宽度覆盖或聊天布局重写。

## 验证

- TypeScript：通过。
- 数字员工定向测试：2 个测试文件、9 项测试全部通过。
- `git diff --check`：通过。
