# 默认员工技能标签接入

日期：2026-07-30

## 背景

数字员工请求层此前已经会把员工对应 AI Forge 作为资源发送，但输入框没有显示原版技能标签，用户无法直观看到默认上下文。

## 改动

- 将当前员工映射为原版 `forge` mention。
- 欢迎页和对话详情页输入框自动显示该默认标签。
- 输入框清空或发送后自动恢复缺失的默认标签。
- 保留原版 `@` 多标签、附件、输入内容提取和发送逻辑。
- 修正程序化插入 mention 时可能误删光标前一个字符的问题。
- 请求层继续保留员工技能兜底和重复资源过滤。

## 验证

- `yarn tsc --noEmit -p tsconfig.json`：通过。
- 数字员工 resolver 与选择页测试：8 项通过。
- `git diff --check`：通过。
