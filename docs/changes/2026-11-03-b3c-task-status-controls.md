1. 当前 React 18 / Ant Design 4 环境复用现有 ahooks 原生拖拽能力，不增加依赖。保留原有列表和本地品牌样式，新增总数后的六卡布局在窄容器切为三列；窄屏任务视图设置最小展示高度，避免图表收缩。
2. 参考 `reorderFilterKeys` 的向右操作是“插入目标前”，相邻向右移动不改变顺序。本地明确按“移动到目标位置”处理，左右相邻移动均有效，并与键盘移动使用同一规则。
3. 拖拽 payload 增加面板 scope，只接受本面板拖拽；非法、外部和同位置 payload 不重排。拖拽后的浏览器 click 在当轮被抑制，避免误触筛选；定时器在组件卸载时清理。
4. 抽出 `taskStatusUtils.ts` 统一统计、过滤和稳定排序。既有看板仍识别未知状态，既有真实时间与终态结束点规则保留。
