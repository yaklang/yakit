## 行为变化

客户端对接官方 `AIStartParams.RuntimeContextSizeLimit`（protobuf 字段号 51），停止下发旧 `TimelineContentSizeLimit`。旧字段仍保留在客户端协议中，以便读取既有数据。

- 设置页名称改为“运行时上下文大小”，沿用现有表单和 KB 输入，新增说明；新配置默认 300 KB。
- 设置页值在 `formatAIAgentSetting` 中只换算一次：300 KB → 307200 字节。0、留空或非法值表示使用引擎默认阈值。
- 历史会话和定时任务中的启动参数已经是字节，经过 `withServerRuntimeContextLimit` 只规范化为安全整数，不再乘 1024；兼容 gRPC int64 字符串。
- 只有旧字段的数据不直接转成新阈值，按官方参考行为丢弃旧阈值，避免旧 60 KB 默认值继续覆盖新的运行时策略。全局设置恢复使用新的 300 KB 默认；已有启动参数缺新字段时发送 0，由引擎决定。
- 配置缓存移除废弃模型字段和旧阈值，保留其余既有缓存行为及显式新阈值，包括 0。
- 定时任务创建、读取、列表和更新响应规范化阈值，编辑名称不会重复换算或丢失已有值。

本批未引入运行时热更新。设置说明明确为创建新会话时生效，历史恢复保留对应会话已有的启动参数；热更新属于 B1-B。数字员工角色、Forge 注入、既有默认模式、页面布局与品牌未调整。
