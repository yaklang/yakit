- **默认配置**：左下 **“⋯ 会话与设置” → “配置”**，面板上方找到 **“单模型模式”**，修改后用于后续新会话。
- **全局开关**：左下 **“⋯ 会话与设置” → “AI模型” → 顶部“线上”列表右上齿轮**（在＋旁边），弹层里找 **“单模型模式”**。

测试：全局关闭时，新会话可自行选择；全局开启时，会话显示被全局覆盖。创建会话后不允许临时改变。实际只使用高质模型的行为需在真实任务中验证。

## 6. 推理强度和探测（B8-C；对应截图 2）

1. 输入框最底下一行，**当前模型名 `standard` 右侧**，就是 **“默认（跟随模型默认）”** 下拉；这是推理强度，不是切换模型名称。
2. 点开下拉，应保持展开，可选择默认 / 关闭 / 低 / 中 / 高等档位；点击后保存配置，后续模型请求使用该配置，实际支持仍由模型提供方决定。
3. 点它右侧 **“探测强度”**。弹层会解释用途并显示“探测中…”；只检测 **xhigh / max** 两个扩展档位，不会自动切换强度。
4. 可能结果：支持时提示具体档位，随后下拉新增相应选项；不支持时明确提示继续使用基础档位；网络 / 模型配置错误、15 秒超时或保存失败会提示可重试。**不支持时选项没有增加是正常结果，但必须有文字说明。**
5. 另一处入口：**“会话与设置 → AI模型 → 模型行铅笔编辑 → 高级配置”**，底部同样有“探测强度”和 Reasoning Effort。
6. 探测中切模型，或手动选择强度，旧探测不得覆盖新值；受管线上配置 / 脚本模型的禁用状态按当前配置边界处理。

## 7. 时间线 Dump（B8-D）

1. 在已有对话顶部点 **“任务内容”**，找到左侧面板顶端 **“时间线 / 任务列表”**；若缩成竖条，先点竖条 **“任务列表”** 或展开箭头。
2. 点 **“时间线”**，再点其上方 **“时间线 Dump”** 按钮。
3. 弹层里有 **“刷新”** 和 **“复制”**；复制的是引擎返回的 Dump 原文。
4. **对话正在运行、连接可用时才能刷新**。你已结束的任务可先测打开和空态；刷新灰色是预期，下次任务运行时再测真实拉取。
5. 无内容时复制禁用；有内容时复制后粘贴到文本编辑器核对。刷新失败应保留上次内容；切会话不能显示另一个会话的 Dump。
